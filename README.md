# ระบบกีฬาสีภายใน — ราชประชาเกมส์ (แอป PWA)

โรงเรียนราชประชานุเคราะห์ ๔๘ จังหวัดจันทบุรี · หน้าเว็บ (PWA) โฮสต์บน **GitHub Pages** · ข้อมูลเก็บใน **Google Sheets** ผ่าน **Google Apps Script**

```
ผู้ใช้ (มือถือ/คอม)  ──►  GitHub Pages (index.html, PWA)  ──fetch──►  Apps Script Web App  ──►  Google Sheets
```

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (หน้าเว็บหน้าเดียว) |
| `config.js` | **ที่เดียวที่ต้องแก้** — ใส่ URL ของ Apps Script (`/exec`) |
| `manifest.webmanifest`, `icons/` | ข้อมูลและไอคอนสำหรับติดตั้งเป็นแอป |
| `sw.js` | Service Worker ทำให้เปิดแอปเร็วและเปิดหน้าแอปได้แม้ไม่มีเน็ต |
| `apps-script/Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ (วางใน Google Apps Script) |
| `.nojekyll` | บอก GitHub Pages ให้เสิร์ฟไฟล์ตามจริง (อย่าลบ) |

## ขั้นตอนที่ 1 — ตั้งค่าฝั่งข้อมูล (Google Apps Script)
1. เปิด <https://script.google.com> → **โครงการใหม่** (หรือเปิดโครงการเดิมถ้าเคยทำไว้แล้ว)
2. ลบโค้ดเดิม แล้ววางเนื้อหาจาก `apps-script/Code.gs` ทั้งหมด **(ไม่ต้องมีไฟล์ `index.html` ใน Apps Script)**
3. เลือกฟังก์ชัน `setupSystem` แล้วกด **เรียกใช้ (Run)** หนึ่งครั้ง และกดอนุญาตสิทธิ์
   — ระบบสร้าง Google Sheet และบัญชี `admin` พร้อมรหัสผ่านชั่วคราว ดูได้ที่ **บันทึกการดำเนินการ (Execution log)**
4. **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
5. คัดลอก **URL เว็บแอป** (ลงท้ายด้วย `/exec`)

> แก้ `Code.gs` ภายหลัง: Deploy → **จัดการการทำให้ใช้งานได้** → ✏️ แก้ไข → เวอร์ชัน **เวอร์ชันใหม่** → ทำให้ใช้งานได้ (URL เดิมไม่เปลี่ยน)

## ขั้นตอนที่ 2 — ใส่ URL ในแอป
เปิด `config.js` แล้วแทนที่ข้อความด้วย URL ที่คัดลอกมา:
```js
window.APP_CONFIG = {
  apiUrl: "https://script.google.com/macros/s/xxxxxxxxxxxx/exec"
};
```

## ขั้นตอนที่ 3 — อัปโหลดขึ้น GitHub และเปิด Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `rajaprachagames`) — ตั้งเป็น Public (บัญชีฟรีใช้ Pages ได้เฉพาะ Public)
2. อัปโหลดไฟล์ **ทั้งหมดในโฟลเดอร์นี้** ไว้ที่รากของ repo (ลาก-วางในหน้า **Add file → Upload files** ได้ ต้องรวมโฟลเดอร์ `icons/` และไฟล์ `.nojekyll`)
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

## ขั้นตอนที่ 4 — ติดตั้งเป็นแอปบนมือถือ
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** / เพิ่มลงในหน้าจอหลัก
- **iPhone (Safari):** เปิดลิงก์ → ปุ่มแชร์ → **เพิ่มลงในหน้าจอโฮม**
- **คอมพิวเตอร์ (Chrome/Edge):** ไอคอนติดตั้งที่ช่องที่อยู่เว็บ

## ข้อควรรู้
- **ข้อมูลทั้งหมดอยู่ใน Google Sheet** ไม่ได้อยู่บน GitHub — การอัปเดตตัวแอปบน GitHub ไม่กระทบข้อมูล
- **อัปเดตแอป:** แทนที่ `index.html` ใน repo (ถ้าสร้าง `index.html` ใหม่ ให้เช็กว่า `config.js` ยังมี URL เดิม) ผู้ใช้จะได้เวอร์ชันใหม่เมื่อเปิดแอปครั้งถัดไป
- **ต้องมีอินเทอร์เน็ต** จึงจะโหลด/บันทึกข้อมูลได้ (ออฟไลน์เปิดได้เฉพาะหน้าแอป)
- **ความปลอดภัย:** URL ของ Apps Script เป็นสาธารณะ แต่ทุกการจัดการข้อมูลต้องล็อกอินด้วยบัญชีในระบบ เปลี่ยนรหัสผ่านผู้ดูแลระบบทันทีที่เข้าสู่ระบบครั้งแรก
- **ยังใช้แบบเดิมได้:** ถ้าวาง `index.html` ของ Apps Script เองและเปิดผ่านลิงก์ Web App ก็ยังทำงานได้ตามเดิม
- เมื่อเปิดแอปแล้วขึ้นว่า "ยังไม่ได้ตั้งค่า apiUrl" แปลว่ายังไม่ได้แก้ `config.js`
